# WLR Design Direction

WLR reuses the visual and information-architecture language of Crypto Yield Archive (CYA), adapted for wallet history.

## Visual system

- CYA-style editorial registry layout and information density
- black / near-black background rather than CYA's paper background
- serif display headings + sans body + mono labels
- square corners and thin rules rather than decorative cards
- sticky masthead and separate navigation row
- compact tables, timelines and fact grids
- muted neutral text and lines calibrated for black surfaces

## Semantic color

Color communicates meaning only where the underlying field has meaning.

- active / low: green
- limited / medium: amber
- deprecated / high: orange
- critical / dead: red
- acquired: violet
- rebranded: blue
- discontinued / unknown: neutral gray

Incident severity and lifecycle status remain separate concepts. A wallet with a critical historical incident can still have an active current status.

## Non-goals

- no star ratings
- no safest/best-wallet badge
- no affiliate-ranking UI
- no neon trading-dashboard styling

## Support

WLR currently has no project-specific donation addresses. The initial Support page temporarily shares the current HEI addresses and says so explicitly. Support never affects editorial classification.
